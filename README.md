# 🛒 Amazon Clone

A lightweight, beginner-friendly Amazon Clone built using vanilla **HTML**, **CSS**, and **JavaScript**.

![Amazon Clone](https://images.unsplash.com/photo-1607082348824-0a96f2a4b9da?w=800)

## ✨ Features

- **Amazon Header & Navigation**: Top dark navbar with Amazon logo, delivery location, account links, and cart badge.
- **Live Search**: Instant product filtering as you type into the search bar.
- **Interactive Category Tabs**: Filter products across Electronics, Fashion, Gaming, Home, Books, Beauty, and Today's Deals.
- **Dynamic Product Grid**: Clean e-commerce cards with images, star ratings, and prices.
- **Amazon Dark Mode Toggle**: Instant switch between classic light theme and sleek Amazon Prime dark theme with `localStorage` persistence and OS auto-detection.
- **Sliding Shopping Cart Drawer**:
  - Slide-in cart sidebar with item thumbnails and titles
  - Dynamic subtotal, estimated tax, and grand total calculation
  - Delete individual items or empty cart
  - Simulated checkout with order confirmation
- **Toast Notifications**: Interactive popup alerts when products are added to the cart or settings change.
- **Fully Responsive**: Mobile, tablet, and desktop friendly layout.

## 🚀 Getting Started

No complex build setup required!

### 1. Clone the repository
```bash
git clone https://github.com/tusr23/Amazon-Clone.git
cd Amazon-Clone
```

### 2. Run the project
Run with npm:
```bash
npm run dev
```
Or simply open `index.html` directly in any web browser:
- Double-click `index.html`, or
- Use VS Code Live Server, or
- Run via PowerShell:
  ```powershell
  npx serve -l 5500 .
  ```
  Then visit `http://localhost:5500/`.
